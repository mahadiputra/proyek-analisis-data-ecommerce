# E-Commerce Data Analysis Dashboard

Ini adalah proyek akhir untuk kelas "Belajar Analisis Data dengan Python" di Dicoding. Proyek ini menganalisis dataset E-Commerce Public Dataset dan menampilkan hasilnya dalam bentuk dashboard interaktif menggunakan Streamlit.

## Setup Environment
```bash
pip install -r requirements.txt
```

## Run Streamlit App
```bash
streamlit run dashboard.py
```
